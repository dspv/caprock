# Caprock — go-to-market

Read this file first, then the one file your task needs.

This directory is the counterpart to [`.ai/`](../.ai/00-index.md): where that one
holds how the product is built, this one holds how it reaches people. The split
exists because the two change on different clocks and for different reasons — a
release note is not a channel decision, and a positioning change does not touch
the daemon.

## Rules for this directory

These are narrower than the engineering rules and apply only here.

1. **No invented numbers.** The same rule as [`.ai/06-engineering-rules.md`](../.ai/06-engineering-rules.md)
   § 6, and it binds harder here: marketing copy is where fabricated figures are
   most tempting and most damaging. Every number is measured, sourced with a
   date, or labelled an estimate.

2. **The owner's name is not published.** He works full-time in fintech and
   cannot be publicly attached to this project. First name in video is his
   decision; a surname appears nowhere — not in a channel description, an about
   page, a video caption, or a commit trailer.

3. **Record what failed.** A channel that was tried and did not work is worth
   more written down than a channel that was only ever considered. Negative
   results go in [02-research.md](02-research.md) with the same weight as
   positive ones.

4. **Content claims trace to the product.** A post that cites a figure names
   where it came from, so a reader who installs Caprock can reproduce it.
