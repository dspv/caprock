- **machines:** link a new computer with one key (#1095). `caprock machines
  key` on the computer you work on prints a key that works once, for 15
  minutes, and the command for the new computer: `caprock join <key>` there
  turns on access from anywhere, lets your computer in without an Allow, and
  says what it did and what is next. The key carries no secrets and grants
  nothing a pasted link and Allow do not; it is in no log or file on either
  computer.
