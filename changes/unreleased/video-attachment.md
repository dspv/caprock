- **chat:** a video dropped into a session (`.mov`, `.mp4`, `.m4v`, `.webm`)
  shows in the chat as a video, not as its path: the first frame, the file
  name and its length, and the controls to play it in place. The session
  still gets the path, since Claude Code cannot watch a video. On the phone
  the path stays as it was.
